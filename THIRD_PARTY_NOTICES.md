# Third-party components

At CMake configure time, this project fetches the D2RLoader PluginSDK from
[D2RLoader/PluginSDK](https://github.com/D2RLoader/PluginSDK) at commit
`03a5af9e0feb3f95f95e148e330e01f6635950df` (SDK 0.4.0, Plugin ABI 4). The SDK is licensed under MIT;
its license is available in the upstream repository.
